Cloud Database & Live Sync Settings

Connect your free Supabase database to share live updates real-time between your city device and village academy.

1-Step Supabase Setup (SQL Editor)

Copy and run this query in your Supabase project's SQL Editor tab to create the sync table:

CREATE TABLE IF NOT EXISTS academy_sync (
  key TEXT PRIMARY KEY,
  value JSONB NOT NULL,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);
ALTER TABLE academy_sync ENABLE ROW LEVEL SECURITY;
CREATE POLICY "Allow public full access" ON academy_sync FOR ALL USING (true) WITH CHECK (true);
